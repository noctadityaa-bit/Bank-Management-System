# Project Statement

## Problem Statement

Managing basic banking activities manually can be time-consuming and may lead to errors in maintaining account information and transaction records.

This project provides a simple console-based Bank Management System that allows users to perform common banking operations digitally.

## Scope

The system focuses on basic banking operations such as account creation, login, balance checking, deposits, withdrawals, money transfers, PIN changes and transaction history.

The project is designed as a learning-based banking simulation and does not connect to any real bank or payment system.

## Target Users

- Students learning Python programming
- Beginners learning software development
- Users who want to understand basic banking system workflows

## High-Level Features

- Account creation
- Account authentication using PIN
- Balance management
- Deposit and withdrawal
- Money transfer between accounts
- PIN change
- Transaction history
- JSON-based data storage
- Input validation
- Error handling
- Basic testing
