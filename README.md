# Bank Management System

## Overview

Bank Management System is a Python-based console application that simulates basic banking operations.

The system allows users to create accounts, securely log in using a PIN, check their balance, deposit and withdraw money, transfer money, change their PIN, and view transaction history.

Account data is stored in a JSON file so that information remains available after restarting the application.

## Features

- Create a bank account
- Secure login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- Change PIN
- View transaction history
- Store account data using JSON
- Input validation and error handling
- Basic testing

## Technologies Used

- Python
- JSON
- VS Code
- Git & GitHub

## Project Structure

- `main.py` - Main program and menu
- `account.py` - Account creation
- `authentication.py` - Login system
- `transactions.py` - Deposit, withdrawal and transaction history
- `transfer.py` - Money transfer
- `validation.py` - Input validation
- `storage.py` - Data loading and saving
- `tests.py` - Basic testing
- `accounts.json` - Account data
